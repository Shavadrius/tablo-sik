# Табло результатов — Осенний Кубок СИК

Статичные страницы для ТВ (1920×1080), которые читают результаты из Google-таблицы и обновляются сами каждые 20 секунд.

| Страница | Что показывает |
|---|---|
| `index.html` | Общая: основная дисциплина (суммы по турам) и мультиигры (очки по блокам) рядом |
| `chgk.html` | Основная дисциплина: каждый вопрос квадратиком, суммы туров, итог |
| `multi.html` | Мультиигры: очки по блокам, сумма процентов |

## Структура

```
.github/workflows/deploy.yml   публикация на GitHub Pages
site/                          всё, что публикуется
  index.html, chgk.html, multi.html
  app.js        логика: загрузка таблицы, места, ДОП, медали, вёрстка
  styles.css    оформление
  config.js     ID Google-таблицы  ← единственное, что нужно менять
  demo.js       тестовые данные (для ?demo)
  fonts.css, assets/   шрифты, логотипы СИК и партнёров
```

## Публикация на GitHub Pages

1. **Создайте репозиторий** на GitHub, например `tablo-sik`. Он должен быть **публичным**: Pages для приватных репозиториев доступен только на платных тарифах.
2. **Залейте файлы** (из папки, где лежит этот README):
   ```bash
   git init
   git add .
   git commit -m "Табло"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/tablo-sik.git
   git push -u origin main
   ```
3. **Включите Pages через Actions:** репозиторий → **Settings** → **Pages** → в разделе **Build and deployment** поле **Source** → выберите **GitHub Actions**. Больше ничего там настраивать не нужно.
4. **Дождитесь публикации:** вкладка **Actions** → workflow **Deploy**. Если первый запуск упал до шага 3 (Pages ещё не был включён) — откройте его и нажмите **Re-run all jobs**, либо **Run workflow** вручную.
5. **Адрес табло:** `https://<ваш-логин>.github.io/tablo-sik/` — он же виден в Settings → Pages и в зелёном запуске Deploy.

Дальше любое изменение в `main` публикуется само за 1–2 минуты.

## Google-таблица

- ID таблицы записан в `site/config.js`. Если таблица сменится — поменяйте `sheetId` там и сделайте push.
- Доступ к таблице: **Настройки доступа → Все, у кого есть ссылка → Читатель**. Иначе табло покажет красную точку в правом нижнем углу.
- Листы, которые читает табло: «Команды», «ЧГК», «МИ», «Настройки». Не переименовывайте их и заголовки столбцов.

## Ссылки для экранов

| Что | Адрес |
|---|---|
| Общая | `…/tablo-sik/` |
| Основная дисциплина | `…/tablo-sik/chgk.html` |
| Мультиигры | `…/tablo-sik/multi.html` |
| Только студенческий зачёт | `…/tablo-sik/chgk.html?zachet=Студ` |
| Несколько зачётов | `…/tablo-sik/?zachet=Корп,Студ` |
| Другая таблица | `…/tablo-sik/?id=<ID таблицы>` |
| Тестовые данные | `…/tablo-sik/?demo` |

Ссылку проще всего собрать на самой странице: наведите мышь на левый нижний угол — выедет панель, выберите страницу и зачёты и нажмите **«Скопировать ссылку для ТВ»**.

## На ТВ

- Откройте ссылку в браузере и нажмите **F11** (или **F** на странице) — полный экран.
- Курсор прячется сам через 3 секунды.
- Точка в правом нижнем углу: зелёная — данные из таблицы, жёлтая — тестовые, красная (мигает) — таблица недоступна, на экране последние полученные данные.
- Клавиши 1 / 2 / 3 переключают общую / ЧГК / МИ.

После обновления файлов на GitHub браузер может ещё несколько минут показывать старую версию — обновите страницу с **Ctrl+F5**.
